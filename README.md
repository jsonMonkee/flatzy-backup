# Flatzy Kolkata 🏠✨

**Kolkata's Hassle-Free Rental Discovery Web Platform**

Flatzy Kolkata is a modern real estate discovery platform built specifically for students, bachelors, IT professionals, and families looking for rental flats across Kolkata (New Town, Salt Lake, Sector V, Rajarhat, and EM Bypass) without broker spam, fake photos, or gatekeeping.

---

## 🚀 Key Features

- 📹 **Flatzy Reel & Video Walkthrough Gallery**: Real, unfiltered room-by-room video tours of verified rental flats with TikTok/Instagram-style vertical reel player, double-tap to like, audio toggle, and tap-to-navigate (front/back).
- 🌐 **Bilingual Support (English & Bengali)**: Instant one-click toggle (`EN / বাংলা`) with full persistent localization across all pages and native *Hind Siliguri* typography.
- 🎯 **Interactive Smart Filters**: Filter by neighborhood (New Town, Salt Lake, Sector V, Shapoorji), unit type (`1 RK / Studio`, `1 BHK`, `2 BHK`, `3 BHK`) with human capacity indicators, budget ranges, and furnishing.
- 💬 **Direct Inquiries & WhatsApp Connect**: One-click **"Enquire Flat"** modal and pre-filled WhatsApp chat triggers connecting renters directly to verified brokers/owners.
- ❤️ **Interactive Wishlist Drawer**: Save favorite properties, calculate combined rent, and trigger direct inquiries with instant toast feedback.
- 🔗 **Share & Copy Link Modal**: Clean dialog box with property preview and one-tap link copying.
- 🏙️ **Cityscape Visual Experience**: Handcrafted Kolkata skyline illustrations, glassmorphic UI, and responsive modern design.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: TailwindCSS + Vanilla CSS design tokens
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, custom CSS micro-animations
- **Fonts**: Google Fonts (Poppins, Plus Jakarta Sans, Hind Siliguri)

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/JoyTheSloth/Flatzy.git

# Navigate to project folder
cd Flatzy

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Building for Production

```bash
npm run build
```
